# Hostile `ssh_run` calls. Every entry must be refused by
# `policy::check_request` for a preset whose parameters accept anything
# their type allows (string and path patterns `.*`, int 0 to i64::MAX) —
# the checks below hold whatever the patterns say. CI runs them:
# `cargo test hostile_corpus`.
#
# One entry per line:  <command> <params as JSON>  # <what it tests> (since vX.Y.Z)
# The commands of that preset:
#   word  echo {v}            v: string
#   path  cat {v}             v: path
#   num   head -n {v} f       v: int
#   opt   ls --color={v}      v: enum auto | never
# The input ends at the first "  # "; lines starting with '#' are comments.
# Corpus escapes (\\, \n, \u{XXXX}, \{c*N}) apply before the JSON is read,
# so a JSON escape is written with a doubled backslash: \\u0000.
